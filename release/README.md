| 文件 | 大小 | 说明 |
|---|---|---|

## 怎么确认自己装的是哪一版

**更新前请先看这个，避免装到旧包还以为没更新。**

- **文件名带版本号**：`ebook_reader-1.0.1.apk`。旧版叫 `1.0.0`，名字不同就不会混
- **应用内显示版本**：书架页左上角标题下面有一行小字 `v1.0.1`
- 如果你打开应用看到的是 `v1.0.0`，说明装的是旧包，需要重新下载

### 版本历史

| 版本 | 变更 |
|---|---|
| **1.0.1** | 修：**字号只改标题、改不了正文**（真实电子书常在 `p` 上写死字号，继承值抢不过元素自身声明）。改进：**滚动更顺** —— 去掉每次滚动重建整个页面、关闭对中文无用的断字、默认改为上下滚动（原生滚动，比 JS 操作 CSS 多列快得多） |
| 1.0.0 | 首个可用版本：本地导入 EPUB → 阅读 → 彩色高亮 + 批注 → 导出 Markdown |

> ⚠️ 从 1.0.0 升级到 1.0.1 **必须重新下载 APK 并覆盖安装**。旧包的 `<html>` 字号方案对
> 自带 `p { font-size: ... }` 的电子书无效，这是 1.0.1 修掉的核心问题。


## 安装 APK

点 `.apk` 文件 → 点 **View raw** → 下载 → 安装。
系统提示「未知来源」时选**仍要安装**（它没有正式证书，是自签名包）。

## 导入电子书

打开 App → **导入 EPUB** → 在文件选择器里找到下载好的 `.epub` → 选中。

## 关于《世说新语.epub》的来源与权利

- **原文**：南朝宋·刘义庆（403–444），属于**公有领域**，无版权限制。
- **本 EPUB 文件**：由开源公版书项目 [文硕阁](https://github.com/zhpelo/wenshuoge)（官网 <https://www.wenshuoge.com/>）整理制作，该项目声明其内容为公共版权书籍、免费提供下载与二次分享。
- **内容特征**：EPUB 3.0，37 个章节文件（`.html` 扩展名但为合法严格 XHTML），0 个 `<script>` 标签，UTF-8 中文。
- **一处保留**：首个章节开头带有「文硕阁」字样，是制作方插入的标识，非原文内容。

> 我采信了文硕阁的公版声明，但未逐本核实其全部 13,846 册藏书。《世说新语》是五世纪古籍，公版无疑。

## 为什么没有《控制论与科学方法论》

因为**它不在公有领域**。金观涛、华国凡合著，1983 年初版，两位作者健在，且 **2025 年刚由万有引力书系修订再版（ISBN 9787218183282）**。网上流传的"DRM-free 版本"属于盗版，本项目不提供。

另外要说明：本阅读器**只支持无 DRM 的 EPUB**，不做 DRM 破解。所以从微信读书、京东读书等平台购买的加密电子书，即使付费了也无法在此打开 —— 这是设计上的明确边界。

想读这本书，正当途径是购买正版（京东/当当搜 ISBN `9787218183282`）或通过图书馆数字借阅。
